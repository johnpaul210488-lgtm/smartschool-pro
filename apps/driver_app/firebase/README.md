# Firebase (driver app)

Yahan Firebase console se download ki hui `google-services.json` rakhein (file ka naam bilkul yahi ho).

- Package name Firebase mein yahi hona chahiye: `com.smartschool.smartschool_driver`
- File rakhne ke baad CI build mein Firebase automatic jud jata hai (`tools/ci/firebase_setup.py`).
- File na ho to app bina push ke banti hai (koi error nahi).
