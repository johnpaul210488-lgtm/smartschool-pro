# Database

**Engine:** Microsoft SQL Server 2022 (any edition; Express is fine for a single school).
PostgreSQL remains a drop-in option later (EF Core provider swap) — the schema avoids
SQL-Server-only data types beyond filtered indexes.

| File | Purpose |
|---|---|
| `001_schema.sql` | Hand-reviewable DDL for every table, key, index, CHECK constraint. Mirrors the EF Core model exactly. |
| `002_seed.sql` | Idempotent seed: `admin`, 2 classes (1-A/2-A), 2 drivers with logins (`driver1`/`driver2`), 2 buses, 5 students, plus optional demo extras (teacher1/parent1, fee challans). |
| `000_ef_reference_idempotent.sql` | Auto-generated by `dotnet ef migrations script --idempotent`. Regenerate after any model change — do not hand-edit. |

## Two supported provisioning paths (pick one, never mix on the same DB)

**A — EF Core migrations (recommended, keeps schema in lock-step with code):**
```powershell
cd SmartSchoolPro
dotnet ef database update --project src/SmartSchool.Infrastructure --startup-project src/SmartSchool.API
```

**B — Manual T-SQL:**
```powershell
sqlcmd -S localhost,1433 -U sa -P "Your_strong!Passw0rd" -C -i database/sqlserver/001_schema.sql
sqlcmd -S localhost,1433 -U sa -P "Your_strong!Passw0rd" -C -i database/sqlserver/002_seed.sql
```
(or paste the two files into SSMS / Azure Data Studio and run in order)

> Note: path B skips EF's `__EFMigrationsHistory`; if you later adopt `dotnet ef database update`,
> baseline it with `dotnet ef database update InitialCreate --no-build` after inserting the
> history row, or just continue managing via SQL.

## Conventions

- All `*Utc` columns are UTC `DATETIME2`; Pakistan time conversion happens only at the API edge (`Common/PkTime.cs`).
- Enum columns are `nvarchar` with `CHECK` constraints (`PickIn`/`DropOut`, `Pending`/`Paid`/…), so raw SQL reads naturally.
- High-volume tables (`BusAttendance`, `WhatsAppLogs`, `DeviceTokens`) use `BIGINT` keys.
- `Students.IsActive` etc. are soft-delete flags; nothing with history is hard-deleted.
- Password hashes are PBKDF2-SHA256: `{iterations}.{saltBase64}.{hashBase64}`.

## Helpful queries

```sql
-- Today's boarding feed (converts stored UTC to Pakistan time)
SELECT s.FullName, b.BusNumber, a.[Type],
       SWITCHOFFSET(TODATETIMEOFFSET(a.TimestampUtc, '+00:00'), '+05:00') AS PakistanTime
FROM dbo.BusAttendance a
JOIN dbo.Students s ON s.Id = a.StudentId
JOIN dbo.Buses b     ON b.Id = a.BusId
ORDER BY a.TimestampUtc DESC;

-- WhatsApp pipeline health
SELECT [Status], COUNT(*) FROM dbo.WhatsAppLogs GROUP BY [Status];
```
